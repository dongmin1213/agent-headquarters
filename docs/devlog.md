## 2026-09-29 — 설계와 첫 동작

**출발점.** 수익 자동화 파이프라인(유튜브 제작 자동화)을 돌리면서 여러 에이전트 탭을 사람이 직접 오가며 지시·전달하는 방식이 병목이 됐다. "회장은 CEO에게만 말하고, CEO가 팀을 꾸려 운영한다"는 구조로 새로 만들기로 했다.

**설계 초안 v2.1과 리뷰.** 오케스트레이터 설계를 두 독립 리뷰어(다른 모델 계열 1, 새 Claude 세션 1)에게 검토받았고 둘 다 **NO SIGN**. 주요 지적:
- CEO가 직접 분석·문서를 쓰면 스스로 검증하는 셈이 된다 → CEO는 판단·배정만, 초안은 작업자가 쓴다.
- 작업자의 "완료" 주장과 종료 코드 0을 믿으면 안 된다 → 완료 계약 파일 + 하네스가 직접 재검증.
- 승인은 대상이 바뀌면 무효여야 한다 → 계획 해시에 묶고 만료를 둔다.

**스택을 실측으로 결정.** 펫·데몬 후보를 같은 맥에서 띄워 메모리를 쟀다 → [0002](decisions/0002-stack.md). Swift 펫 약 15MB, TypeScript 데몬.

**데몬 1차.** SQLite(WAL) 저장소, SSE 이벤트 버스, 팀 스케줄러(종료 코드 계약: 0 한가/3 대기/75 한도/그 외 오류), 127.0.0.1 전용 + Bearer 토큰 + Origin 거부.

**CEO 턴.** `claude -p`를 읽기 전용 도구(Read/Glob/Grep), JSON 스키마 출력, 세션 재개로 호출. 출력은 "질문 ≤3개" 또는 "계획+작업 지시서" 중 정확히 하나 → [0004](decisions/0004-ceo-turn.md).
첫 실제 요청 "펫 말풍선 글자 크기를 설정 파일에서 바꿀 수 있게"에 대해 L1 등급, Sonnet 구현+검증 계획을 $0.38에 생성, 승인 대기까지 확인.

**펫.**
- 처음엔 모든 팀을 걸어다니게 했더니 산만했다 → 바쁘거나 결정이 필요한 캐릭터만 표시, 걷기 제거, 드래그 위치 기억.
- CPU 10.5% → 변경 시에만 갱신, 바쁜 캐릭터만 애니메이션, 12fps 타이머로 **약 2.5%**.
- `open`으로 실행하면 안 보이는 버그: 바탕화면 폴더의 토큰을 메인 스레드에서 읽다 macOS 권한 창에 막힘 → 토큰을 `~/.config/hq`로 이동.
- 다른 도구(Orca) 세션까지 펫에 띄웠다가 "hq는 Orca와 완전히 별개여야 한다"는 피드백으로 해당 기능 제거.

**이전 하네스의 교훈 재검토.** 회사에서 만들었던 멀티 에이전트 하네스의 운영 기록을 전부 다시 읽고, 개인 환경에 옮길 원칙을 정리 → [0005](decisions/0005-lessons-from-previous-harness.md).
