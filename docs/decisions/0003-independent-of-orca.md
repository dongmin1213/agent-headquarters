# 0003. 기존 터미널형 오케스트레이터(Orca)와 분리

- 상태: 채택 (2026-09-29)

## 맥락
Orca 같은 IDE형 도구(약 900MB)는 탭·터미널 중심이라 사람이 계속 화면을 보며 조작해야 한다.

## 결정
- hq는 Orca와 완전히 별개로 동작한다. Orca 세션을 읽거나 표시하지 않는다.
- 작업자는 Claude Code CLI를 헤드리스로 실행한다. 직접 들여다볼 필요가 있을 때는 Claude Code 자체 기능(`claude --bg`, `claude attach`, `--resume`)을 쓴다.
- 화면은 데스크 펫(요약·결정)과 필요 시 로컬 웹 페이지(상세)로 대신한다.

## 결과
- 새로 만들어야 하는 것: worktree 관리, 완료 계약, 생존·폭주 감시, 활동 로그. 대신 무거운 IDE 의존이 사라진다.
