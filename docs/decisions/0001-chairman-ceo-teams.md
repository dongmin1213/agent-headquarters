# 0001. 회장 → CEO → 팀 구조

- 상태: 채택 (2026-09-29)

## 맥락
에이전트 탭을 여러 개 띄워 사람이 직접 지시·전달·확인하면 사람이 병목이 된다. 사람은 한 곳에만 말하고 싶다.

## 결정
- 사람(회장)은 CEO 에이전트 하나에만 요청한다.
- CEO는 **판단·배정·통합만** 한다. 분석·코드·문서 초안은 작업자가 쓴다. (스스로 쓴 결과를 스스로 판정하면 오류가 걸러지지 않는다.)
- CEO는 작업자에게 "어디를 무엇을 어떻게"를 구체적으로 적은 지시서를 준다. 분석을 작업자에게 떠넘기지 않는다.
- 상시 팀(예: 수익 자동화)은 자체 주기로 돌고, CEO는 관리·감독한다.
- 작업자가 반드시 낮은 모델일 필요는 없다. 역할×등급으로 모델을 고른다.

## 결과
- 사람의 개입은 질문 답변, 계획 승인, 결과 수락, 병합 승인으로 좁혀진다.
