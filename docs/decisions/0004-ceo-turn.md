# 0004. CEO 턴 설계

- 상태: 채택 (2026-09-29)

## 결정
- 호출: `claude -p --output-format json --json-schema <스키마>`, 도구는 Read/Glob/Grep만, `.env*` 읽기 금지, 사용자 설정·MCP 미로딩(`--setting-sources ''`, `--strict-mcp-config`).
- 출력은 정확히 하나: **질문 1~3개** 또는 **계획**(요약, 가정, 작업 목록: 역할·등급·모델·소유 경로·수용 기준·지시서·의존).
- 검증: 알려진 프로젝트, 의존 존재, 병렬 작업의 소유 경로 겹침 금지. 형식 오류는 1회 정정 요청.
- 세션 ID를 저장해 다음 턴은 `--resume`, 실패 시 새 세션 1회 재시도.
- 등급 L0~L3(6개 항목 0~2점, 금전·보안·비가역은 거부권). 역할×등급으로 모델 배정.
- 계획 승인은 계획 해시에 묶고 24시간 만료. 무응답은 승인이 아니다.
